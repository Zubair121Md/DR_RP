# Journal shortlist (Version B exploratory DR / medical-AI)

**Policy:** Only list legitimate venues. Separate ₹0 / no-APC routes from APC OA. Verify APC and indexing on official pages before submission; fees change.

**Manuscript fit:** Exploratory methods + transparent protocol deviation + external validation. Prefer journals that accept careful negative/mixed findings. Avoid top clinical journals that expect confirmatory multi-centre claims.

## C. Recommended order for this manuscript

1. **PLOS ONE** — best cultural fit for Version B transparency + exploratory scope (APC or fee assistance).  
2. **Scientific Reports** — similar; slightly more selective (APC).  
3. **IEEE Access** — if framing as applied ML systems with schedule/protocol engineering disclosure (APC).  
4. **Indian Journal of Ophthalmology** — only if rewritten with stronger clinical framing and acceptance of exploratory AI methods (verify fees).  
5. Hybrid subscription title — if ₹0 is mandatory and OA is not required immediately.

---

## D. Not recommended as first choice

- High-impact clinical journals expecting confirmatory multi-site deployment claims.  
- Predatory / unknown APC journals with false indexing claims.  
- Venues that forbid exploratory protocol-deviation disclosures.
